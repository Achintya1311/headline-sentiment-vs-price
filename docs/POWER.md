# Statistical power of the pre-registered follow-up test

Day 84 (hub `CRITIQUES.md` R18). The original "Pre-registered follow-up
test" data gate (README, set when that section was first written) required
"at least 100 headlines resolved to a priced ticker" before computing a
correlation. This page asks the question that gate never asked: what size
of true correlation could 100 headlines actually have detected?

Both tables below are generated by `sentiment.stats.minimum_detectable_r`
and `sentiment.stats.required_n_for_r` (`tests/test_stats.py` pins the
values quoted here against those functions, so this page cannot silently
drift from the code that backs it). Both use the standard Fisher
z-transform minimum-detectable-effect approximation (two-sided test,
alpha = 0.05, 80% power) - the same transform `pearson_with_ci` already
uses for this project's confidence intervals, just solved for `n` instead
of for the interval.

## Minimum detectable |r| at a given sample size

| n (headlines) | min. detectable \|r\| |
|---:|---:|
| 23 (Day 1 snapshot) | 0.556 |
| 42 (Day 77 fix-phase, current corpus) | 0.421 |
| 50 | 0.387 |
| 100 (the old gate) | 0.277 |
| 250 | 0.176 |
| 500 | 0.125 |
| **1,000 (the new gate)** | **0.088** |
| 2,000 | 0.063 |

At the old 100-headline gate, nothing smaller than about |r| = 0.28 could
ever have been distinguished from zero at 80% power - a correlation that
large between a single headline's sentiment and a next-session return
would be a remarkably strong effect for this kind of signal. A real but
modest effect (r = 0.10, say) was never detectable at that sample size: a
null result there was never evidence of "no effect," only of "not enough
data to tell," exactly the underpowered-vs-null distinction this project's
README already draws for the 22-month RELIANCE factor-model screen check
(see `fama-french-factor-model`) and the 137-month GULFOILLUB panel
question (R17) - this is the same question, asked of this repo's own
pre-registered test.

## Sample size needed to detect a given |r|

| target \|r\| | n needed |
|---:|---:|
| 0.05 | 3,137 |
| **0.10** | **783** |
| 0.15 | 347 |
| 0.20 | 194 |
| 0.28 (the old gate's own ceiling) | 98 |
| 0.30 | 85 |

A plausible small real effect in this kind of headline-sentiment setting
(r around 0.10) needs on the order of 780-790 resolved headlines to detect
at 80% power - not 100. That is why README's "Pre-registered follow-up
test" section raised the data gate to at least 1,000 headlines (resolved to
a priced ticker, after excluding headlines that name their own price move),
over at least 30 distinct sessions, from at least 3 distinct sources: the
new floor is sized to actually be able to detect a modest real effect,
not merely to look more thorough than the old one.

This is still an approximation (asymptotically normal, like the CI it
reuses), not an exact small-sample calculation, and it says nothing about
whether a real effect of any particular size exists here - only how much
data would be needed to tell, at a few candidate sizes. Reaching the gate
does not promise a significant result; it promises only that the test run
at that point is capable of detecting a modest one if it is there.
